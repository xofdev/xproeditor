# Localization & RTL

Every label, tooltip, placeholder and message the editor renders comes from
one typed `EditorDictionary`. English is the default; Persian (`fa`) ships
built in.

## Use a built-in language

```tsx
<ProEditor locale="fa" editorDir="rtl" defaultValue={blocks} />   // React
<DocRenderer locale="fa" editorDir="rtl" blocks={blocks} />
```

```vue
<ProEditor locale="fa" editor-dir="rtl" :model-value="blocks" />
```

`locale` only changes the UI language. Text direction is separate:
`editorDir` sets the default for new and empty blocks, and every block with
text picks its own direction from its first strong character — a Persian
paragraph is RTL and an English one LTR in the same document. Blocks with no
letters (`/`, numbers, emoji) inherit `editorDir`. `localeDirection('fa')`
returns `'rtl'` if you want to derive one from the other.

## Override strings

`dictionary` is merged over the chosen locale, so pass only what you change:

```tsx
<ProEditor
  locale="en"
  dictionary={{
    placeholders: { focused: 'Write something brilliant…' },
    blockTypes: { callout: 'Note' },
  }}
/>
```

## Add a language

Provide every key (TypeScript will tell you which are missing) and pass it as
`dictionary`:

```ts
import { EN_DICTIONARY, type EditorDictionary } from '@xproeditor/core'

export const DE: EditorDictionary = {
  ...EN_DICTIONARY,
  toolbar: { ...EN_DICTIONARY.toolbar, bold: 'Fett', italic: 'Kursiv' /* … */ },
  // …
}

<ProEditor dictionary={DE} />
```

Contributions of new built-in locales are welcome: add the dictionary to
`packages/core/src/i18n.ts` and to `EDITOR_LOCALES`; the i18n test checks that
it covers every English key.

## Using the dictionary in your own components

- React: `useEditorDictionary()` inside any child of `ProEditor`,
  `BlockEditor`, `DocRenderer` or `EditorI18nProvider`.
- Vue: `useEditorDictionary()` (returns a computed) inside any descendant, or
  `provideEditorI18n(locale, dictionary)` to set it up yourself.
- Anywhere: `resolveEditorDictionary(locale, overrides)` from core.

## What isn't translated

Block *content* (it's the user's text), code-language names, and the default
Ask AI commands (`DEFAULT_AI_COMMANDS`) — pass your own localized
`ai.commands` if you use Ask AI.
