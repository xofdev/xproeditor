[`.changeset/`](../.changeset)).

## Versioning policy

- **Patch** — bug fixes, no API change.
- **Minor** — new blocks, props, methods or exports; existing documents and
  code keep working.
- **Major** — any breaking change to a public prop, export or the persisted
  `Block` shape. Majors are always called out at the top of the entry with
  migration steps.

The persisted document format (`BlocksContent`, `version: 1`) has not changed
since the first release. Documents written by a newer version load in older
versions with unknown block types shown as plain paragraphs.

## Upgrading to core 0.5 / vue 0.6 / react 0.6

No code changes are required. Things you may want to adopt:

- `locale="fa"` / `dictionary` — [i18n.md](i18n.md)
- The document API on the editor ref — [api.md](api.md)
- `onUploadError` / `@upload-error` to show your own upload failures
- `/embed` and `/toc` blocks — [block-model.md](block-model.md)
- Spellcheck is now **on** by default; pass `spellCheck={false}` /
  `:spellcheck="false"` to keep the old behaviour.
- Headings in `blocksToHtmlContent` output now carry `id` attributes, and
  headings in non-Latin scripts get real anchors instead of `heading-N` — if
  you deep-link to old `heading-N` anchors of non-Latin headings, update
  those links.
