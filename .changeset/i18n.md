Localization. Every label, tooltip, placeholder and message now comes from a typed dictionary: pass `locale="fa"` for the built-in Persian UI (English stays the default) or `dictionary={{ … }}` to override any string or ship another language. Works on `ProEditor`, `BlockEditor` and `DocRenderer`, including portaled menus. Core exports `EN_DICTIONARY`, `FA_DICTIONARY`, `resolveEditorDictionary` and `localeDirection`; React exports `EditorI18nProvider` / `useEditorDictionary`, Vue exports `provideEditorI18n` / `useEditorDictionary`.
